# Taxatietooling

Hoofdmenu van de Taxatietooling van Jesper Kivits Vastgoedadvies: inloggen, tools en klanten.

Deze repository bevat alleen het inlogscherm en het hoofdmenu. De tools, de data en alle keuzes staan afgeschermd in Supabase en worden pas na inloggen geladen. Toegang is alleen mogelijk voor teamleden die de beheerder heeft klaargezet.

- `index.html`: hoofdmenu (GitHub Pages)
- `.github/workflows/ping.yml`: dagelijkse ping zodat het gratis Supabase-project niet pauzeert
